# Distorted Divinity — архитектура

Движок: **Godot 4.3+ (GDScript)**. Разрешение: **480×270**, целочисленный масштаб.
Арт: пиксель-арт, персонажи/NPC 32×32, предметы 64×64.

## Главные правила

1. **Контент = данные.** Оружие, враги, регионы, предметы, боссы — это `.tres` ресурсы
   в `data/`. Новый контент добавляется файлом данных, а не правкой кода.
2. **Сущности собираются из компонентов** (`Health`, позже `Shooter`, `Mover`), а не из наследования.
3. **Системы общаются через `EventBus`** (`core/event_bus.gd`), без прямых ссылок друг на друга.
4. **Три независимых слоя забега:** мета-карта → этаж → комната.
5. **Run State и Meta Save раздельно:** что сбрасывается за забег и что остаётся навсегда.
6. **Спрайты подменяются данными:** у сущности есть поле `sprite`; пока оно пустое,
   рисуется цветной плейсхолдер.

## Структура папок

```
core/       автозагрузки: event_bus, input_setup (позже game_state, save_system)
data/       ресурсы: fire_modes/, weapons/, enemies/ (позже regions/, items/, bosses/)
entities/   player, enemy, projectile, components/
systems/    (план) run_graph, floor_generator, bullet_pool, boss_fsm
scenes/     комнаты и сцены (сейчас test_room)
ui/         HUD, меню
assets/     спрайты и музыка
```

## Управление

WASD — движение · стрелки — стрельба · Q — смена оружия (2 слота) ·
E — альт-огонь · пробел — рывок (короткая неуязвимость, перезарядка 5 с).
Раскладка регистрируется кодом в `core/input_setup.gd`.

## Оружие

`WeaponData` содержит два `FireMode` (`primary` на стрелках, `alt` на E).
Тип снаряда, скорость, разброс и число пуль задаются данными. Теги (`tags`)
нужны для условий маршрутов (например, `holy`, `gall`).

## Структура забега (план)

- **Мета-карта = граф регионов.** `RegionData`: тема, пул комнат, пул врагов, босс,
  число этажей, список выходов.
- **`RegionExit`**: целевой регион + условия (босс убит, этажей ≥ N, у игрока есть тег
  снаряжения, выбран маршрут). Недоступные выходы показываются затемнёнными с подсказкой.
- **Этаж:** сетка комнат в стиле Isaac (старт, обычные, сокровищница, магазин, босс).
- **Комната:** враги и паттерны пуль.
- Пост-дивинити: отдельная фаза после победы над Искажённым Божеством.

## Ближайший план

1. Вертикальный срез: игрок, рывок, 2 оружия, один враг, тестовая комната (готово).
2. Пул пуль и паттерны пуль как данные (`BulletPattern`).
3. Машина состояний боссов.
4. `RegionData` + генератор этажа.
5. Run State / Meta Save.
