# Distorted Divinity — архитектура

Движок: **Godot 4.3+ (GDScript)**. Разрешение: **480×270**, целочисленный масштаб.
Арт: пиксель-арт, персонажи/NPC 32×32, предметы 64×64.

## Главные правила

1. **Контент = данные.** Оружие, враги, регионы, предметы, боссы — это `.tres` ресурсы
   в `data/`. Новый контент добавляется файлом данных, а не правкой кода.
2. **Сущности собираются из компонентов** (`Health`, позже `Shooter`, `Mover`), а не из наследования.
3. **Системы общаются через `EventBus`** (`core/event_bus.gd`), без прямых ссылок друг на друга.
4. **Три независимых слоя забега:** мета-карта → этаж → комната.
5. **Run State и Meta Save раздельно:** что сбрасывается за забег и что остаётся навсегда.
6. **Спрайты подменяются данными:** у сущности есть поле `sprite`; пока оно пустое,
   рисуется цветной плейсхолдер.

## Структура папок

```
core/       автозагрузки: event_bus, input_setup (позже game_state, save_system)
data/       ресурсы: fire_modes/, weapons/, enemies/ (позже regions/, items/, bosses/)
entities/   player, enemy, projectile, melee, zone, components/
systems/    (план) run_graph, floor_generator, bullet_pool, boss_fsm
scenes/     комнаты и сцены (сейчас test_room)
ui/         HUD, меню
assets/     спрайты и музыка
```

## Управление

WASD — движение · стрелки — стрельба · Q — смена оружия (2 слота) ·
E — альт (когда шкала заряда полная) · пробел — рывок (короткая неуязвимость, перезарядка 5 с).
Раскладка регистрируется кодом в `core/input_setup.gd`.

## Оружие

`WeaponData` = название + редкость + теги + два `FireMode` (`primary` на стрелках, `alt` на E).

`FireMode.kind` определяет поведение режима:

| kind         | что делает                                                      |
|--------------|-----------------------------------------------------------------|
| `PROJECTILE` | пули: скорость, число, разброс (360 = кольцо)                   |
| `MELEE`      | `THRUST` — выпад копьём по линии (пробивает); `SWEEP` — замах на 360° вокруг игрока; каждого врага бьёт один раз за удар |
| `ZONE`       | лужа на земле: урон врагам внутри, ускорение игрока внутри      |

Модификаторы снарядов (комбинируются): `pierce` (через скольких врагов проходит,
-1 = бесконечно), `bounces` (рикошеты от стен), `homing_degrees` (самонаведение).
Любой режим может дать игроку временное ускорение (`speed_boost`); ускорения
не складываются, максимум ×1.5 (`Player.MAX_SPEED_MULT`).

### Альт

Альт намного сильнее обычной атаки, но доступен только при полной шкале.
Шкала копится от урона, нанесённого врагам (`EventBus.enemy_damaged`),
сколько нужно — задаётся `WeaponData.alt_damage_needed`. После альта шкала обнуляется.
Это основная ручка баланса: чем больше число, тем реже альт.

### Текущий набор

| Оружие                     | Основной огонь                         | Альт                          |
|----------------------------|----------------------------------------|-------------------------------|
| Святое копьё               | ближний выпад, ускорение ×1.5 на 1 с   | Вихрь Праведника (круг)       |
| Жезл Праведника            | частые слабые самонаводящиеся пули     | Хор Серафимов (кольцо, наведение) |
| Золотой плазменный арбалет | редкое; мощная стрела, пробивает 2     | Плазменный залп (5 стрел)     |
| Посох Горечи               | лужа вокруг игрока, ускоряет внутри    | Жёлчный прилив (большая лужа) |
| Зеркальный раскол          | рикошетящие осколки                    | Каскад отражений (кольцо)     |

## Слои стен и пуль

Стены лежат на слоях 1+2. Тела (игрок, враги) сталкиваются со слоем 1.
Пули каждый кадр пускают луч по слою 2 — так работают рикошет и гибель о стену.
(Позже: пул пуль и более дешёвая проверка, когда пуль станет много.)

## Враги

`EnemyData` описывает врага целиком; `behavior` выбирает поведение, остальное — числа.

| behavior | что делает | пример |
|----------|------------|--------|
| `RANGED` | держит дистанцию (отступает, если игрок ближе 70%), стреляет паттерном: `RING` кольцо, `AIMED` веер в игрока (можно с предупреждением-лучом), `SPIRAL` вращающиеся серии | Певчий, Слепой Лучник, Херувим-Прялка |
| `CHARGE` | бежит на игрока, контактный урон | Исступлённый, Червеныш |
| `LUNGE` | подходит, замирает с линией-предупреждением, делает рывок, затем стоит уязвимым | Таран |

Любой враг может иметь контактный урон (`contact_damage`) и распадаться при смерти на других
(`split_into` + `split_count`): Выводок → 3 Червеныша. Рывок игрока (i-frames) спасает от контакта и пуль.

Новый враг = новый `.tres` в `data/enemies/`; код трогать не надо, пока хватает этих поведений.

## Структура забега (план)

- **Мета-карта = граф регионов.** `RegionData`: тема, пул комнат, пул врагов, босс,
  число этажей, список выходов.
- **`RegionExit`**: целевой регион + условия (босс убит, этажей ≥ N, у игрока есть тег
  снаряжения, выбран маршрут). Недоступные выходы показываются затемнёнными с подсказкой.
- **Этаж:** сетка комнат в стиле Isaac (старт, обычные, сокровищница, магазин, босс).
- **Комната:** враги и паттерны пуль.
- Пост-дивинити: отдельная фаза после победы над Искажённым Божеством.

## Дебаг в тестовой комнате

1–5 — поставить оружие в активный слот · F — заполнить шкалу альта.

## Ближайший план

1. Набор оружия на данных (готово), настройка баланса по ощущениям.
2. Пул пуль и паттерны пуль врагов как данные (`BulletPattern`).
3. Машина состояний боссов.
4. `RegionData` + генератор этажа.
5. Run State / Meta Save.
