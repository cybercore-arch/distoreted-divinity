# Distorted Divinity

Быстрый 2D bullet hell roguelike с видом сверху. Godot 4.3+.

Запуск: открыть папку в Godot и нажать F5 (главная сцена — `scenes/test_floor.tscn`).

Управление: WASD — движение, стрелки — стрельба, Q — смена оружия, E — альт-огонь, пробел — рывок.

Архитектура: см. [ARCHITECTURE.md](ARCHITECTURE.md).
